# Витрины для книжного рекомендательного сервиса на PySpark

**Задача.** Собрать на кластере витрины данных о прослушивании и чтении книг для рекомендательной системы.

## Что сделано

- скрипт `spark-submit` с параметрами периода, гео и разрезов; запуск на YARN в режиме cluster;
- чтение и запись Parquet в S3 (ключи — из переменных окружения, per-bucket настройки S3A);
- пять витрин: пользователь × контент, жанры, профиль пользователя, контент, дневная активность;
- разбор физического плана (`explain`) и оптимизация: ранняя фильтрация, broadcast-join, замена оконных функций агрегациями.

## Результат

- фильтрация до join сократила объём обрабатываемых строк с ~1 млн до 126 тыс.;
- подробный отчёт с анализом данных и плана выполнения — в [analysis.md](analysis.md).

**Стек:** PySpark 3.3, YARN, S3 (Parquet)
