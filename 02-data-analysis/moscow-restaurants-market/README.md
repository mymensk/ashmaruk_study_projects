# Исследование рынка общепита Москвы

**Задача.** Провести исследовательский анализ ~8 тыс. заведений Москвы (данные Яндекс Карт, 2022) и подготовить рекомендации инвесторам по выбору формата и района для нового заведения.

## Что сделано

- предобработка: типы, пропуски, дубликаты, объединение двух источников;
- анализ категорий, сетевых и несетевых заведений, посадочных мест, рейтингов и среднего чека по округам;
- корреляционный анализ рейтинга (phik).

## Результат

- самый высокий средний чек — в Центральном и Западном округах, в Западном втрое меньше конкурентов;
- рейтинг почти не зависит от числа мест, чека и района — вероятно, решает сервис;
- среди сетевых форматов лидируют булочные (61%) и пиццерии (52%).

**Стек:** Python, pandas, matplotlib, seaborn, phik

**Решение:** [`moscow_restaurants_market.ipynb`](moscow_restaurants_market.ipynb)
