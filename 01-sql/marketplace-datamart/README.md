# Витрина данных маркетплейса «ВсёТут» и ad hoc-задачи

**Задача.** Построить пользовательскую витрину данных маркетплейса и ответить на продуктовые вопросы на её основе.

## Что сделано

- витрина `product_user_features`: заказы, чеки, рейтинги, отмены, рассрочки, промокоды, способы оплаты по каждому пользователю топ-3 регионов (8 CTE);
- сегментация пользователей по числу заказов;
- ранжирование пользователей по среднему чеку;
- региональная статистика и когортный анализ по месяцу первого заказа.

## Результат

- ~96% пользователей совершают только один заказ — главная точка роста в повторных покупках;
- рассрочка используется примерно в половине заказов, промокоды — около 4%;
- во второй половине 2023 года рос приток клиентов, но снижались рейтинг заказов и срок активности.

**Стек:** PostgreSQL: CTE, CASE, оконные и агрегатные функции, DATE_TRUNC
