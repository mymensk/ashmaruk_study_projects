# A/B-тест алгоритма рекомендаций в приложении коротких видео

**Задача.** Спланировать A/B-тест нового рекомендательного алгоритма, проконтролировать корректность проведения и оценить его влияние на долю «успешных» первых сессий (4+ просмотренных страницы).

## Что сделано

- EDA исторических данных: регистрации, глубина просмотра, доля успешных сессий;
- расчёт размера выборки (MDE = 3% от базового уровня) и длительности теста;
- контроль корректности сплитования: размеры групп, пересечения, однородность по устройствам и регионам;
- проверка гипотезы z-тестом для долей, анализ мощности.

## Результат

- доля успешных сессий: 31,57% (A) против 31,47% (B), p-value = 0,58 — роста нет;
- рекомендация: не внедрять алгоритм в текущем виде, при перезапуске набрать расчётную выборку и следить за барьерными метриками монетизации.

**Стек:** Python, pandas, statsmodels, matplotlib

**Решение:** [`ab_test_video_feed.ipynb`](ab_test_video_feed.ipynb)

**A/B test of a recommendation algorithm in a short-video app**

Test design (sample size for MDE = 3%, duration), split sanity checks (group sizes, overlaps, device and region balance) and a one-sided z-test for proportions on the share of "successful" first sessions.

**Key result:** No effect (31.57% vs 31.47%, p = 0.58) — do not ship
