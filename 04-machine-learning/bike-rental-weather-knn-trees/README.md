# Прогноз спроса на прокат велосипедов по погоде

**Задача.** Предсказать спрос на аренду велосипедов с учётом погодных условий и выбрать модель для продакшена.

## Что сделано

- базовая модель и EDA;
- KNN и решающее дерево, подбор гиперпараметров (Optuna), кросс-валидация;
- сравнение по RMSE, MAE, R², анализ важности признаков, сохранение модели.

## Результат

- решающее дерево показало лучшие метрики и меньший разброс на кросс-валидации;
- спрос определяют температура, солнечная активность и влажность; снижают — ночь, осадки и зима;
- обслуживание станций стоит планировать на дни с неблагоприятным прогнозом.

**Стек:** Python, pandas, scikit-learn, Optuna, joblib
