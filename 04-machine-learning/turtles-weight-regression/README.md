# Прогноз массы морских черепах по замерам

**Задача.** Построить линейную модель для системы компьютерного зрения, которая оценивает массу черепахи без взвешивания, по габаритным замерам.

## Что сделано

- EDA и отбор записей по виду *Chelonia mydas*;
- разбиение 60/20/20, сравнение способов масштабирования;
- сравнение LinearRegression, Lasso, Ridge и SGDRegressor с разными функциями потерь;
- анализ важности признаков.

## Результат

- лучшая модель — SGDRegressor (squared_error) со стандартизацией: MAE = 3,68, MAPE = 4%, R² = 0,981;
- ключевые признаки — длина и ширина панциря, габариты головы.

**Стек:** Python, pandas, scikit-learn, matplotlib

**Решение:** [`turtles_weight_regression.ipynb`](turtles_weight_regression.ipynb)
