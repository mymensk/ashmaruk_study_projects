# Экспресс-оценка стоимости подержанного автомобиля

**Задача.** Заменить ручную оценку автомобиля моделью, которая за доли секунды выдаёт оффер в мобильном приложении. Переоценка — прямой убыток, недооценка — потеря клиента.

## Что сделано

- EDA на 8 000 сделок, отложенный тест на 2 000;
- сравнение CatBoost, LightGBM и XGBoost, подбор гиперпараметров в Optuna;
- бизнес-метрики: доля опасных переплат (Overpricing Rate > 20%) и упущенная выгода от занижения цены;
- интерпретация модели через SHAP, поиск рискованных брендов и регионов.

## Результат

- лучшая модель — CatBoost: R² = 0,874 на тесте, средняя ошибка ≈ 11% от медианной цены;
- выделены сегменты (бренды, регионы, электромобили и гибриды) для ручной проверки экспертом.

**Стек:** Python, pandas, CatBoost, LightGBM, XGBoost, Optuna, SHAP

**Решение:** [`car_price_gradient_boosting.ipynb`](car_price_gradient_boosting.ipynb)
